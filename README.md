# Absorb

一款基于 Audiobookshelf 的现代有声书客户端，提供卡片式播放体验。

> 🤖 **本项目全部由 AI 开发，未经人工审核，稳定性无法保证；仅提供 Android 版本。**

**本仓库**是 [pounat/absorb](https://github.com/pounat/absorb) 的 Fork，后续所有修改均由 AI（OpenCode / Claude Code）生成并提交，改动集中在 Android 平台的界面体验与功能增强。

- ⚠️ **稳定性无法保证** — 改动范围广、缺少系统性回归测试，可能引入上游没有的 Bug、性能回退或机型兼容问题。请勿当作生产级软件使用，重要数据请自行备份。
- 📱 **仅 Android 平台** — 只构建并发布 Android APK；不提供 iOS 构建，也未对 iOS 做过验证。如需 iOS 版本请使用上游仓库。
- 🌐 **界面语言以简体中文为主** — 基础语言包继承自上游社区翻译，Fork 新增文案由 AI 翻译，其中部分中文经人工校对修饰。

## 功能特性

- **卡片式播放器** — 全屏"正在收听"卡片替代传统播放界面
- **Audiobookshelf 集成** — 连接自托管 Audiobookshelf 服务器
- **离线播放** — 下载书籍，无需网络即可收听
- **播客支持** — 带章节的播客，富 HTML 描述
- **备份与恢复** — 导出所有设置到 `.absorb` 文件，支持账户凭证迁移
- **多账户** — 登录多个服务器并切换
- **睡眠定时器** — 可视化进度条、自动定时、摇一摇重置
- **播放速度** — 精细滑块控制，按书记忆速度
- **自动回退** — 可配置暂停后自动回退时长
- **均衡器** — 内置音频 EQ，支持频段和预设
- **书签** — 任意时刻保存和跳转
- **章节导航** — 双进度条（全书 + 章节）
- **搜索与筛选** — 全文搜索、按进度/类型/系列筛选、多种排序
- **Audible 评分** — 在书籍上查看 Audible 星级评分
- **自动播放下一集** — 自动继续系列中的下一本书或下一个播客
- **Android Auto & Apple CarPlay** — 车载浏览和收听
- **Chromecast** — 投屏播放（仅 Android）
- **自定义请求头** — 适配反向代理
- **OIDC/SSO 登录** — OpenID Connect 支持
- **服务器管理** — 管理用户、备份、播客
- **收听统计** — 追踪收听历史
- **Audnexus 元数据** — 丰富封面、描述、系列信息
- **发现即将上架** — 通过 Audible 目录发现系列新书
- **笔记** — 按书籍或章节记录
- **播放列表与收藏** — 创建自定义分组并播放
- **最近播放** — 快速访问收听历史
- **实时同步** — 通过 socket.io 同步进度、书库变更
- **桌面小组件** — Android 桌面正在播放小组件
- **车载模式** — 大按钮驾驶 UI（无需 Android Auto）
- **国际化** — 支持多语言，界面以简体中文为主

- **封面状态标签** — 书籍卡片展示已下载章节占比
- **睡眠定时器增强** — 新增时分滚轮选择器、摇一摇模式、淡入淡出策略
- **完成徽章模式** — 封面右上角"已完成"徽章支持文字/仅图标/关闭三种显示
- **缓存分项手动清理** — 设置页按封面/JSON/流式/会话/歌词/电子书分类清理，含残留临时文件清扫
- **服务器日志本地化** — 支持多语言展示日志等级与过滤选项
- **更新代理加速** — GitHub 下载可配置代理地址，APK 分块并行下载，支持改用浏览器下载
- **设置布局自定义** — 拖拽调整设置区块顺序、隐藏不需要的区块

### v1.21.16+425 — 自动切章不再漏播片头、章节跳转自动播放与封面重试

- **自动切到下一章不再先漏一小段片头**：在「一章一个文件」的书中，自动进下一章是播放器直接换轨，本来不发 seek，因此没有任何预跳。`position` 把新轨的 0 换算成恰好等于章节起点，而自动跳过的判定是严格大于，起点这个读数被忽略——要等下一个 position tick 才触发，这期间片头开头已经播了出来，听起来像一个孤立音效或几个字。上一章/下一章按钮与章节列表此前都已预跳到片头跳过点（代码注释里写的就是这个原因），唯独自动切章漏了，现补上第四条预跳路径
- **自动切章的预跳刻意不写「用户 seek」标记、也不预置每章一次的跳过状态**：伪造标记会反过来触发 3 秒抑制窗口，那正是本问题的成因；预置状态则会让预跳失败时整段片头完整放出。预跳只负责 seek，失败时仍由原有的 position tick 路径兜底
- **新增设置「章节跳转后自动播放」（默认开启）**：暂停状态下用章节列表跳转、或按上一章/下一章，原本只定位不播放，点击看上去毫无动静；现在跳转后直接开始播放。关闭则恢复旧行为，便于先把章节对好再开始听。走既有的 `play()` 入口，因此不会触发暂停恢复时的自动回退到上一章尾巴，也不会被其他设备的位置覆盖
- **章节跳转的自动播放改为统一施加**：三个导航方法各有多个成功出口（上一章就有 4 个），分散插入极易遗漏；现改为实现返回「是否真的跳转了」，由一个包装器统一处理。这样没有章节、没有下一章、或下一章就是全书结尾的空操作不会误触发播放
- **封面加载失败会自行恢复**：失败时把结果从 Flutter `ImageCache` 逐出，并按 600ms / 2s / 5s 最多重试 3 次，URL 或缓存 key 变化时重置计数。原先失败结果被缓存后不会重试，只能手动刷新。真正没有封面的书重试耗尽后仍渲染同一个标题占位符，失败结果照旧缓存，不会每次重建都发请求
- **封面缓存按显示宽度分条，这解释了为何只有新加的书会退化**：`stableCoverCacheKey` 把 width 计入 key，同一本书的 96/120/400/800/1200 是彼此独立的条目。而回到前台若经历离线→在线跳变，`PaintingBinding.imageCache` 的内存缓存会被整体清空——缺少当前宽度磁盘缓存的近期书籍必须重新联网，一旦这次首屏请求失败就会停在标题占位符

### v1.21.16+421 — 章节跳过精度、服务器地址输入与封面状态

- **章节前后跳过改用文件时间轴**：章节边界不再直接取元数据的 `start`/`end`，而是换算到播放器实际寻址所用的那条时间轴。元数据在拆包重编码后会漂移数秒，此前「跳过片头 20 秒」可能只前进 16 秒、「跳过片尾 7 秒」仍会放出 5 秒
- **章节边界一次算完并缓存**：边界换算需要对轨道表做线性扫描，而跳过判定每个 position tick 都要跑一遍（片尾窗口内还有 120ms 快速轮询），章节较多时表现为切章卡顿、时间轴反复刷新。现按输入引用 + 长度判定代次后缓存，每 tick 仅做常数次标量比较
- **「倍速调整时间」默认改为关闭**：跳过按音频内容时间计算，而该选项默认开启会让进度显示按倍速换算，1.25 倍速下跳过片头 20 秒时界面显示成 16 秒，与实际落点不符。选项本身保留，可随时开启
- **跳过设置面板重做**：标题改用与入口按钮一致的「跳过片头/片尾」，开关收进标题行；原先顶部的大字号数字行与下方滑块显示的是同一组数值，且视觉重量压过控件，改为安静的状态行
- **秒数移到标签左侧**：显示为「跳过片头 20 秒」，数值沿用原有强调样式，标签行按文字基线对齐以适应两种字号混排
- **片头/片尾滑块新增左右「减号 / 加号」按钮**：步进 1 秒，到 0 / 120 自动禁用，配 0 与 120 首尾标签，样式对齐「播放速度」
- **跳过面板新增功能提示**（`hint_chapter_skip`）：说明按书保存，且改动从下一章开始生效
- **本地服务器地址支持裸 IP 输入**：自动补 `http://` 与隐式端口 `13378`；关闭协议自动推断，避免把主机名静默改写成 HTTPS 而指向无人监听的 TLS 端口。远程服务器与登录页维持原有行为
- **本地服务器连通状态常驻显示**：状态行移到「设置」按钮左侧，未连通时明确显示状态，而不是只弹一次 toast 便无从确认地址是否可达
- **封面状态不再被 payload 误判为「无封面」**：library payload 能证明封面存在，但无法证明封面不存在——`coverPath` 为 null 只是服务器刚加书、封面文件尚未生成的**正常中间态**，当成「确定无封面」会把书钉进无封面集合，`getCoverUrl` 返回 null、网格与首页渲染成标题文字。现在只有真实路径才能**清除**标记，任何 payload 都不能新增标记。需说明：这一条只是收窄了误判面，解锁后退化成标题占位符另有原因，见 [v1.21.16+425](#v12116-425--自动切章不再漏播片头章节跳转自动播放与封面重试)
- **无封面书籍的观感不变**：封面请求 404 后由 `StableCachedNetworkImage` 的 `errorWidget` 渲染同一个标题占位符，失败结果会被缓存，不会每次重建重复请求
- **`registerHasCover` 仅在集合实际变化时通知监听器**，消除整页循环导致的逐行重建

### v1.21.15+415 — 下载状态显示与操作体验
